# Study Mate

A study companion application to help you manage and organize your study sessions effectively.

## Prerequisites

- Node.js (version 26.8.1 or later)
- npm

## Set up

```bash
npm install
```

## Development

To start the development server, run:

```bash
npm run dev
```

Code style, formatting, and type checking:

```bash
npm run lint
npm run format
npm run typecheck
```
